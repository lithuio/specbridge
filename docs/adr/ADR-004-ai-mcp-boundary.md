# ADR-004：AI 只作建议、MCP 只读已批准规格

- **状态**：Accepted（P1 设计边界确认，非交付承诺）
- **日期**：2026-11-01

## 背景

客户需求文本可能不可信，AI 可能虚构范围、错误推断客户意图或被提示词注入。Agent 如果能直接修改审批记录，会绕过现实商业授权。

## 决策

AI 分析作为 P1，经 DeepSeek Adapter 返回结构化建议，Schema 校验后展示为草稿；用户显式确认才能产生正式 Revision。P0 必须完全不依赖模型。

MCP 首版只使用本地 stdio，按项目作用域读取**已批准**变更快照，不提供 approve/reject/修改已批准内容的工具；Token 可撤销、可过期、仅哈希存储。远程 MCP/OAuth 延后。

## 备选

1. 自主 Agent 帮客户审批：不具备授权依据、误审批成本高。
2. 直接把 AI 回复落库：格式和事实不可控。
3. 直接从 MCP 访问数据库：绕过授权层。

## 代价

需要一次人审 UI、错误降级与输出 Schema；降低全自动化程度，但显著提高可解释性和安全性。

## 验证

AI 失败不影响核心链路；所有 AI 建议带标签；MCP 不能读未批准或跨项目规格，无法审批。
