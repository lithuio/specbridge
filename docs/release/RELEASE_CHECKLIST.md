# SpecBridge — Release Checklist

- [ ] P0 验收项全部通过，已公开记录仍未解决问题。
- [ ] 登录、租户隔离、版本审批与交付验收的 E2E 流程通过。
- [ ] 完成关键 API 权限/并发/冲突负向测试。
- [ ] 无明文密钥；生产与开发配置分离。
- [ ] HTTPS、数据库持久化、迁移审查和备份恢复演练完成。
- [ ] 镜像/Commit SHA/迁移版本有记录，支持回滚。
- [ ] README、部署步骤、演示账号（若有）和隐私声明经过审查。
- [ ] CI 绿色，人工批准发布，Git Tag 与 GitHub Release 对应。
- [ ] 未实现的 P1 功能不得在介绍中声称已上线。
