# 项目背景资料 — 人工验收

2026-11-13，工作流 B。0005/0006 只获批应用于 `127.0.0.1:5434/specbridge_test`；开发库5433仍需单独授权，不能直接运行默认迁移命令。本轮所有账号、文档、真实模型输入均是隔离合成资料。

## 准备和正常流程

1. 以 Owner 创建项目“会员积分”，初始范围填“只查询积分，不包含支付”。创建成功后项目概览提供第二步可选背景上传；跳过不影响创建需求。
2. 本地新建 UTF-8 `客户访谈.txt`：

   ```text
   访谈记录：会员积分有效期一年，用户希望到期前收到提醒。
   尚未确认：提前几天提醒、短信还是站内通知、失败是否重试。
   ```

3. 上传并进入“背景资料”。默认仅 Owner / 显式项目 Developer 可读。支持文本 PDF、DOCX、MD/TXT；扫描件没有 OCR。点击“查看 v1 文字”，核对真实页/段位置。
4. 绑定 Client 后，用 Client 的独立浏览器登录；此时应看不到资料。Owner 点击“共享 v1”，先核对确认区，再点击“确认操作”。Client 刷新后只能读取这个共享版本。
5. 上传同一文档的替换版本 `内部补充.txt`，内容填“内部估算尚未确认，不能承诺交付日期”。新版本保持内部；Client 的名字、内容和版本仍来自 v1。Owner 再显式共享 v2 才会切换。Developer 可以上传，但不能共享、撤回或停用。
6. 撤回共享后，Client 列表与旧来源链接都不能读取；停用后所有角色的新检索及来源读取拒绝。重新启用仅恢复内部使用，不自动恢复共享。

## AI 示例

创建需求“积分到期提醒”，原文“希望系统提醒即将过期的积分”。在需求工作台：

- “帮我问清楚” → “生成澄清建议”。预览应列出本轮背景版本/段落链接；只引用已共享背景，Owner 也不会自动把内部文件带入对客生成。可以只保存个人问题工作稿，不创建 Revision。
- “帮我整理规格” → 生成建议，人工编辑后再预览发布。背景是参考资料，不能被当作客户确认或商业批准；未确认问题仍须保留。
- Owner 打开 Copilot，输入：“检索会员积分背景，说明现有记录、阻塞点和仍待确认的问题，并附版本来源。”可以读取内部资料，但必须区分内部参考与客户事实；点击来源验证。Client 相同提问只能得到共享版本的片段。

模型不会保证读完整个文件：每次检索最多4段，每段最多1000字符；未命中不能推断项目没有资料。来源真实不代表模型解释准确。AI 不自动 Ready、Submit、审批或验收，MCP 不读取背景文件。

## 失败、冲突和边界

- 上传损坏 PDF、空文件或扫描件：显示固定失败说明；已创建项目和既有可用版本保持。失败原件清理，重试产生新版本。
- 超过10 MiB或错误格式：明确拒绝。项目20份文档包含停用身份；100 MiB包含 READY 历史和在途预留，停用不会释放历史配额。
- 两个窗口同时共享：旧窗口409，先刷新核对，再重新确认。不要静默刷新 expectedVersion 后重放。
- 模拟网络丢失上传响应：文件保留、上传按钮暂停。先“刷新列表并核对”，确认已有版本后不要重复上传。服务端没有承诺上传幂等。
- 解析中断：在两分钟后再次上传，会先将旧任务清理并记为 INTERRUPTED。没有常驻恢复队列或后台自动重试。
- 版本列表最多显示最近50次上传及当前/共享版本；旧来源链接仍可重新授权读取。文本详情按20段翻页。

## 环境与运行

API 的解析工作进程要求 Linux/WSL、Node22及 `/usr/bin/prlimit`、可读取的 `/proc`；部署需保留 `apps/api/scripts/document-parser.mjs` 与对应依赖。默认原件目录为运行API用户的 `~/.local/share/specbridge/documents`，0700目录/0600文件；可通过仅服务端 `DOCUMENT_STORAGE_DIR` 指定仓库外私有目录。不要指向 Web public、共享挂载或仓库。页面不提供原件下载，仅展示授权纯文本。

常规验证：`pnpm test:e2e:documents`、构建API/Web后 `pnpm test:browser:documents`，均使用隔离库和Mock模型。受控真实验证单独执行 `R08_REAL_PROVIDER=1 node scripts/with-env.mjs .env.test pnpm --filter web test:e2e documents-real-ai.spec.ts`；只有API子进程读取.env，普通CI禁止真实调用。
