# Copilot 人工确认提案 — C 人工验收

2026-11-13。0005/0006/0007仅在已获批准的 `127.0.0.1:5434/specbridge_test` 应用；开发5433尚未启用这些新增表，不要自行运行开发迁移命令。已有R08手动流程和外部MCP边界保持。

## 从对话进入具体工作

1. 创建合成项目“月度清单”，创建需求“按月导出”，原文填“希望按月份导出项目需求，字段和格式尚未确认”。
2. 打开全局Copilot，问：“当前需求有哪些阻塞点？请读取需求来源，建议下一步。”核对真实业务来源，点击“为此需求准备操作”；也可以直接展开“准备操作与个人提案”，选择当前项目中的需求。
3. 选择“发布澄清问题”和“重新生成建议（仅共享背景）”，点击“准备个人提案”。这一步只保存本人可见提案，不新增问题、Revision或商业草稿。内部对话/工具正文不会自动转入生成；对客建议重新走A的共享资料上下文。
4. 修改一个问题，取消另一个“采用”复选框，或删除不需要的问题。先“保存预览修改”，再“核对并继续”。检查目标需求、业务版本、正文、来源和待确认事项；只有“确认执行此提案”才发布选中的问题。
5. 查看回执及需求结果，原始输入不变，没有自动Revision、Ready、Submit或审批。已执行提案只读；重复执行不会重复发布。

## 个人工作稿与规格

- 可以在A工作台只保存本人澄清/规格工作稿，然后在Copilot选择“复制本人工作稿（无需 AI）”。复制不会修改或删除原工作稿，也不把复制动作当成发布。已经采用的问题会被排除；已有同版发布标记的规格不能再次用于准备。
- 提案绑定复制时的工作稿ID/版本和业务版本；原工作稿更新/删除后，旧提案执行会被拒绝，需重新准备。C发布后原工作稿仍保留，旧业务基线不能自动重放；人工重新核对后才能再次采用。
- Owner/Developer可选择“创建 Revision”，编辑正文和验收标准后明确确认。仍受R04 Pending规则保护；创建后为澄清中，需从原页面人工标记就绪。Client只有发布问题任务，Owner也不能代读或执行Client的个人提案。
- AI故障时可以复制本人工作稿或回到原手动编辑器，商业草稿准备也不依赖模型。没有本人工作稿时，在需求工作台先保存手动输入即可。

## 商业草稿

1. 先从原需求页面人工创建可用Revision并标记就绪。此处不会替你完成该状态转换。
2. 选择“创建商业草稿”。范围和标准来自最新就绪规格；工时、金额、币种和工期默认空值，不能视为AI报价或已确认承诺。
3. 人工填写或保留未确认空值；金额按最小货币单位输入，如CNY的1000表示10元。保存预览、核对并确认，只创建DRAFT，不提交审批。
4. 返回任务列表，选择“更新商业草稿”及具体草稿版本，编辑后确认。必须仍是同需求的DRAFT且绑定最新就绪Revision；旧业务/商业版本或已提交草稿会拒绝，正式冻结历史不会被修改。

## 冲突、未知结果、有效期与隐私

- 两窗口编辑同一提案：旧版本409，保留本地输入。可复制文字，再明确加载服务器预览或删除旧提案重新准备；不会自动替换版本重放。
- 准备/保存/执行网络结果未知：先“核对服务器记录”。执行会按已有operationId查本人提案状态；已成功则显示回执，不再执行。尚未完成时需人工重新核对，当前页面保留同一操作编号，避免产生第二次写入。
- 关闭重开Drawer保留当前内存中的编辑及未知执行编号；刷新后未保存输入会丢失，可从个人提案列表恢复已保存版本/回执。没有localStorage或完整聊天持久化。
- 提案24小时过期后不能保存修改或执行；可由本人删除未执行提案。过期不等于自动删除。每人每需求最多100份未执行提案，包含过期；列表优先展示未执行项，支持分页。已执行提案及回执保留、不可修改或删除；当前没有自动清理周期。
- 撤回背景共享、停用资料、来源版本改变、项目归档或成员/会话失效后，确认必须失败。退出登录与等待项目锁的并发场景有真实数据库负面测试。
- 公开活动、日志、Observe不包含个人提案正文；审计仅动作类型、对象ID/版本和固定元信息。过去已经看到/发送的数据不能靠撤回共享收回。
