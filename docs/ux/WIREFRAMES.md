
### 交互约束

- 未授权动作从前端隐藏，但后端始终验证。
- 审批按钮旁显示 Version No + 冻结时间；点击前弹出版本摘要确认。
- 请求失败 409 时提供“已有新版本，刷新再操作”。
- AI 生成文案必须明确标注“建议，不是已确认条款”。
- 状态空白、加载、失败、权限不足都有明确页面反馈。

### v0.2 关键交互补充

- 创建 Project 后可暂不绑定 Client，但 Submit 变更之前若未绑定则在 UI 给出 Owner 指定已注册邮箱入口；接口必须校验。
- Client 绑定由 Owner 独立操作（`PUT /projects/:id/client`），首次变更正式提交后 UI 标记客户绑定不可修改。
- 交付附件仅为 HTTPS 链接，不显示文件上传按钮；初始范围只读，不显示签约/签署操作。
